# Lexi · 护理预科与英语学习

双语学习应用：英语单词学习 + Athabasca BIOL 235 护理预科。

## 功能

### 英语空间
- 3200+ 词库（初/中/高级分级）
- 看图选词、听音辨词、拼写挑战
- 句子练习、短文跟读
- 120 分钟学习驾驶舱

### 护理预科（BIOL 235）
- Chapter 1: 65 术语、92 道题、11 费曼任务
- 考点提炼、解剖图、模拟考试（50题/60分钟）
- 磨耳朵：术语+句子循环播放，支持息屏
- 中/EN 双语界面
